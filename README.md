## Project Overview
This project involves the development of an **end-to-end Healthcare Dashboard** using **Power BI**. 

The dashboard provides insights into hospital performance, resource utilization, and patient-level data, enabling healthcare professionals to make data-driven decisions.

### Key Features:
- **Consolidated View:** Displays an overall summary of hospital performance and key metrics.
- **Monthly Trends View:** Tracks and visualizes monthly patient volumes, admission types, and treatment costs for trend analysis.
- **Patient-Level View:** Implements drill-through functionality to analyze individual patient data, including treatment outcomes and financial metrics.

## Key Achievements
- **Built Interactive Dashboard:** Developed a comprehensive Power BI dashboard featuring Consolidated, Monthly, and Patient-Level views.
- **Real-Time Trend Analysis:** Enabled tracking of patient volumes, admission types, and costs to improve operational planning and forecasting.
- **Patient-Specific Insights:** Implemented drill-through functionality to analyze detailed patient-level data for enhanced decision-making.
